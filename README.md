# Weather & Smart Travel

A Java web app that looks up current weather for a trip's origin and destination, provides basic weather-based travel advice, and stores each search in MySQL. The interface uses JSP, HTML, CSS, and vanilla JavaScript.

## Features

- Search weather by origin and destination city using the OpenWeatherMap Current Weather API.
- Optionally use browser geolocation for the origin weather lookup.
- Receive simple travel advice based on the destination's weather.
- Save search details and weather results to MySQL.

## Requirements

- Java 17 or later
- Apache Maven
- Apache Tomcat 10.1 or later (Jakarta Servlet 6)
- MySQL
- An OpenWeatherMap API key

## Configuration

Set these environment variables before starting Tomcat:

| Variable | Required | Description |
|---|---|---|
| `OPENWEATHER_API_KEY` | For weather lookups | OpenWeatherMap API key |
| `DB_USER` | Yes | MySQL username |
| `DB_PASSWORD` | Yes | MySQL password |
| `DB_URL` | No | JDBC URL override; defaults to a local `weather_travel_db` database |

Example in PowerShell:

```powershell
$env:OPENWEATHER_API_KEY = "your-openweathermap-api-key"
$env:DB_USER = "your-mysql-username"
$env:DB_PASSWORD = "your-mysql-password"
# Optional:
$env:DB_URL = "jdbc:mysql://localhost:3306/weather_travel_db?serverTimezone=UTC"
```

Keep real keys and passwords out of source control. The default JDBC URL is intended for local development; configure TLS and secure database settings for production.

## Database setup

Create the database and a table matching the columns used by the application:

```sql
CREATE DATABASE weather_travel_db;

USE weather_travel_db;

CREATE TABLE trip_history (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    origin VARCHAR(255) NOT NULL,
    destination VARCHAR(255) NOT NULL,
    latitude DECIMAL(10, 7) NULL,
    longitude DECIMAL(10, 7) NULL,
    origin_weather TEXT,
    destination_weather TEXT,
    smart_advice TEXT,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

The application inserts the origin, destination, optional coordinates, weather, and advice. The timestamp is generated by the database.

## Build and run

Build the WAR from the project root:

```powershell
mvn clean package
```

The packaged application is `target/weather-smart-travel.war`. Deploy it to a Tomcat 10.1+ server and start Tomcat. By default, open:

```text
http://localhost:8080/weather-smart-travel/
```

Browser geolocation requires the user's permission and a secure context (HTTPS, or localhost).
